### Roll Cage Designs

In the archive are a couple that I went through that I ended up not using for one reason or another.

### Descriptions
`rollcage_slim.SLDPRT` -- This is the current design, and it uses M2x8mm screws with nuts to tighten. An iteration on this design is to use locking nuts for M2 screws -- This would probably be helpful for nearly all cases of M2 screws. This design is preferred because it allows the part to crumple at the joints instead of splintering carbon fiber everywhere through the rods and gimbal base

`archive/rollcage*.SLDPRT` -- The previous design that relied on string to fasten it together. This is the design on the poster. There used to be an X pattern on top before I realized that it was a dumb idea to block the light source. These designs all used the concept of a rectangular cage extruded from the gimbal as a crumple zone.

### Print settings
In Labriola bambulab on PLA with 0.08mm thickness on "High Quality" with a 20% infill.
