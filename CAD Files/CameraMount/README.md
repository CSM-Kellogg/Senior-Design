### Gimbal Mount Interface Design
This is a customizable file for mounting whatever it may be to the gimbal. The camera mount is shown, and the general mount should be a good template.

### Descriptions
`CameraMount.SLDPRT` -- The mount for the camera
`Mount --template.SLDPRT` -- A template (not used by `CameraMount`) but should be a much easier part to modify.

### Print Settings
Default, can be .20 mm quality at 12% infill with supportcubic or whatever infill pattern gives the least amount of material.
